\begin{problem}
  Prove that between any two distinct real numbers, there is a rational number.
\end{problem}

\begin{solution}
  Let $a, b \in \R$ such that $a < b$. We want to find some $q \in \Q$ such that $a < q < b.$
  Since $a < b$, we have $b - a > 0$. By the Archimedean property, there exists some $n \in \N$ such that $n > \frac{1}{b - a}$.
  Then, we have $n(b - a) > 1$, which implies $nb - na > 1$. Since $na$ is an integer, there exists some $m \in \Z$ such that $na < m \leq na + 1$. Then, we have $na < m \leq na + 1 < nb$, which implies $a < \frac{m}{n} < b$. Thus we can take $q = \frac{m}{n}

\end{solution}
